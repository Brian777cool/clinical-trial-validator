# LLM 病歷抽取評估資料集（模擬肝癌病歷 30 份）

用來評估「LLM 從病歷文字抽取收案欄位，再交給 `validator.py` 核對與判定」這個流程。

> ⚠️ **聲明**：30 份病歷與病患皆為虛構，不含任何真實病歷。病歷文字由 AI（Claude）依預先設定的標準答案協助撰寫，並經本人逐份檢查標準答案與文字是否一致。為避免同一個模型「自己出題、自己作答」而高估表現，抽取時建議使用不同的模型。

## 檔案

| 檔案 | 說明 |
|---|---|
| `notes/P-30xx.txt`、`synthetic_notes.jsonl` | 30 份模擬病歷文字（兩種格式內容相同） |
| `ground_truth.csv` | 每份病歷的標準答案；病歷未記載的欄位為 `MISSING` |
| `emr_rows_P3000.csv` | 對應的模擬 EMR 紀錄，評估時作為核對基準 |
| `expected_outcome.csv` | 假設抽取完全正確時，validator 應給出的判定 |
| `extraction_prompt.md` | 抽取提示詞範本（輸出 JSON） |
| `extract.py` | 呼叫 OpenAI API 逐份抽取，輸出 `extractions.jsonl`（API key 從環境變數讀取） |
| `evaluate.py` | 評估程式：逐欄位計算正確率、幻覺與漏抽次數，並把抽取結果送進 validator |

## 難度設計

| 等級 | 份數 | 內容 |
|---|---|---|
| A | 10 | 標準格式，數值與單位清楚 |
| B | 12 | 常見的真實寫法：×10³/µL、K、g/L、同時列出舊檢驗與最新檢驗、描述性的腹水與肝性腦病變、腫瘤軸向順序不同、過去腫瘤大小、直接膽紅素、大量無關數值、中英夾雜 |
| C | 8 | 陷阱：未做 BIA、未報告頭尾徑、完全未記載神智狀態（應標示缺漏）、否定句（過去有腹水、目前沒有）、INR 受 warfarin 影響、µmol/L 單位、兩顆腫瘤、大量縮寫 |

各份的陷阱說明寫在 `ground_truth.csv` 的 `trap` 欄。

## 標準答案的規則

- 有多次檢驗時取最新一次；單位統一為 /µL、mg/dL、g/dL
- 腫瘤取最大（標的）病灶；長徑＝最長軸向徑、寬徑＝垂直軸向徑、高徑＝頭尾徑
- 病歷沒有記載的欄位一律為 `MISSING`，不得推測（例如沒寫神智狀態，不能當作 `none`）
- P-3027 的 INR 2.45 受 warfarin 影響，抽取仍記錄測得值；validator 會因此把 Child-Pugh 算成 B 級，是刻意保留的討論案例（見下方限制）

## 評估方式

把整個 `llm_eval` 資料夾放在 repo 最外層（和 `skills` 同一層），然後在 `llm_eval` 資料夾內：

1. 執行 `python extract.py --model <模型名稱>`，用 `extraction_prompt.md` 讓 LLM 逐份抽取，結果存成 `extractions.jsonl`（每行一筆 JSON）；API key 請設在環境變數 `OPENAI_API_KEY`，不要寫進任何檔案
2. 執行 `python evaluate.py extractions.jsonl`（會自動使用本資料夾的 `emr_rows_P3000.csv` 作為核對用的 EMR，不需要修改 `mock_emr_db.csv`）

報告的指標：
- 各欄位抽取正確率、整份完全正確的比例（可依 A／B／C 分開看）
- **幻覺**：病歷未記載，LLM 卻給了值的欄位數
- **漏抽**：病歷有記載，LLM 卻標為缺漏的欄位數
- 抽取錯誤中，有多少被 validator 攔下（`Source data mismatch`、`Data Error`、`Missing required field`），而沒有直接影響收案判定

## 限制

- 本資料集的 EMR 與病歷內容一致，所以只要抽錯，validator 幾乎都能攔下。但真實情境中，腹水、肝性腦病變常只記錄在自由文字裡，沒有結構化欄位可以核對，這正是 LLM 抽取最需要、也最難驗證的部分。可以另做一組條件：把 EMR 的腹水與肝性腦病變清空，觀察哪些抽取錯誤會直接影響收案判定。
- 在 P-3023～P-3025，如果 LLM 幻覺給了值，validator 會因為 EMR 那一欄本來就是空白而回報 EMR 格式錯誤並擋下，這並不是真的核對出錯誤，所以「被 validator 攔下」的比例會被高估。
- 為了讓標準答案明確，多數病歷都寫出腫瘤三徑並標示軸向；真實的影像報告多半只寫一或兩個徑，實際的抽取難度會更高。
- 標準答案由一人設定，沒有經過第二位臨床人員獨立覆核。
- 30 份樣本很小，結果只能當作初步觀察。
- P-3027 顯示規則式判定的盲點：使用抗凝血劑時，INR 不能反映肝功能，但規則仍照數值計分，把肝功能可能屬於 A 級的病人算成 B 級。
